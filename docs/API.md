# HTTP API reference

Base URL in local development: `http://127.0.0.1:8000`.
Interactive explorer (generated by FastAPI): `/docs`.

All responses are JSON unless noted. CORS is restricted to `FRONTEND_ORIGINS`.

---

## Service

### `GET /`
`{"message": "Trading Analysis API is running"}`

### `GET /health`
`{"status": "ok", "service": "trading-analysis-api"}` — used by the dashboard's
connection badge. Poll it slowly; it is not a progress signal.

### `GET /engine`
`{"available": true}` — whether the TradingAgents framework can be imported. When
`false`, runs still work but return clearly-labelled mock output.

## Runs

### `POST /runs` -> `202`

Body (extra keys are ignored, camelCase and snake_case both accepted):

| Field | Meaning |
| --- | --- |
| `ticker` | Symbol, e.g. `700`, `NVDA`, `9988.HK`. |
| `analysis_date` / `end_date` | Analysis "as of" date, `YYYY-MM-DD`. |
| `provider` | LLM provider name (must have a key in `.env`). |
| `quick_model`, `deep_model` | Model names, validated against the catalogue. |
| `research_depth` | `Shallow` \| `Medium` \| `Deep` — debate rounds. |
| `selected_analysts` | Subset of `market`, `social`, `news`, `fundamentals`. |
| `stages` | Opt-in stage ids; anything absent is skipped. |
| `language` | Report language, e.g. `English`, `Chinese`. |

Response: `{"run_id": "...", "reused": false, "run": { ...full run... }}`.
An identical payload while the original is still active returns `reused: true`.

Errors: `400` invalid payload or missing provider key, `500` unexpected.

### `GET /runs`
History: a list of run summaries, newest first.

### `GET /runs/{run_id}`
The full record: `status`, `request`, `progress`, `partial`, `reports`,
`decision`, `timings`, `logs`, `artifacts`, `error`. This is the heavy read — use
`/status` for polling.

Status values: `queued`, `running`, `completed`, `error`, `cancelled`.

### `GET /runs/{run_id}/status`  ← poll this one

```json
{
  "run_id": "…", "status": "running", "version": 12,
  "created_at": "…", "updated_at": "…", "started_at": "…", "completed_at": null,
  "progress": {"stage": "risk_debate", "message": "…", "percent": 72,
               "step": 7, "total_steps": 10},
  "decision_ready": false,
  "reports_ready": ["market_report", "bull_report", "bear_report"],
  "artifacts_ready": {"price_chart_json": true, "result_html": false},
  "result_url": null,
  "cancel_requested": false, "attempt_count": 1,
  "poll_after_ms": 1500, "timings": {…}, "error": null
}
```

Send `If-None-Match` with the previous `ETag` and you will usually get
`304 Not Modified`. Refetch heavy endpoints only when `version` changes.
The full report is ready only when `status == "completed"` **and** `result_url`
is present.

### `POST /runs/{run_id}/cancel`
Sets the cancellation flag; the worker stops at the next stage boundary. Reports
already published are kept.

### `GET /runs/{run_id}/logs`
`{"logs": [...]}` — engine log lines, oldest first, capped at 200 entries.

## Reports and decision

### `GET /runs/{run_id}/decision`
The normalised verdict: action, confidence, rationale, executive summary, bull and
bear points, and price levels when the engine supplied them.

### `GET /runs/{run_id}/reports`
Every report finished **so far**, as `{name: markdown}`. Unfinished reports are
absent rather than empty — never a placeholder.

Report names: `market_report`, `sentiment_report`, `news_report`,
`fundamentals_report`, `bull_report`, `bear_report`, `investment_plan`,
`trader_plan`, `risk_aggressive`, `risk_conservative`, `risk_neutral`,
`final_trade_decision`.

### `GET /runs/{run_id}/reports/{report_name}`
One report. `404` if that report does not exist or has not been produced yet.

## Artifacts

### `GET /runs/{run_id}/artifacts`
Absolute URLs (built from `PUBLIC_BASE_URL`) for everything below:
`market_data`, `market_data_json`, `price_chart_json`, `price_chart_png`,
`price_chart_html`, `chart_png`, `chart_html`, `result_html`.

| Endpoint | Content type | Notes |
| --- | --- | --- |
| `GET /runs/{id}/market-data` and `…/market-data.json` | JSON | OHLCV plus indicators. |
| `GET /runs/{id}/price-chart.json` | JSON | Compact payload the React chart reads. |
| `GET /runs/{id}/price-chart.png` | PNG | Static matplotlib image. |
| `GET /runs/{id}/price-chart.html` | HTML | Interactive Plotly chart. |
| `GET /runs/{id}/chart.png`, `…/chart.html` | PNG / HTML | Older names, same content. |
| `GET /runs/{id}/result.html` | HTML | Printable report for the whole run. |

Missing files are rebuilt on demand, so these rarely `404` for a valid run.

## Ad-hoc chart

### `GET /chart/{symbol}`
Query: `range` (e.g. `6mo`, `1y`), optional `run_id` to merge that run's AI
decision into the response. Returns bars, indicator series, detected signals with
human-readable reasons, and support/resistance levels. No AI call, no run needed.

## Providers

### `GET /providers`
```json
{ "active": {"provider": "DeepSeek", "deep_model": "…", "quick_model": "…",
             "configured": true},
  "providers": [ {"provider": "…", "label": "…", "configured": true,
                  "supports_balance": true, "env_keys": ["…"],
                  "deep_models": [...], "quick_models": [...],
                  "default_deep_model": "…", "default_quick_model": "…"} ] }
```

### `GET /providers/credit?provider=…`
Key check and, where the provider publishes it (DeepSeek, OpenRouter), the
remaining balance and its currency. Other providers return only "the key works" —
no balance is invented. `400` if no provider is configured, `404` if unknown.

### `POST /providers/active`
Body `{"provider": "...", "deep_model": "...", "quick_model": "..."}`. Validates
the models, rewrites the provider lines in `.env`, and returns the new active
selection plus `"restart_required": true` — **restart uvicorn** for it to take
effect. `400` if no key is saved for that provider or a model name is invalid.

API keys are never returned by any endpoint.

## MCP — `POST /mcp`

`/mcp` is a stateless MCP Streamable HTTP endpoint generated by the official
Python MCP SDK. MCP clients perform initialize/tool discovery/tool calls through
this single endpoint; do not treat it as a REST endpoint or open it as a normal
web page.

| Tool | Maps to | Notes |
| --- | --- | --- |
| `create_analysis` | `create_or_reuse_run` | Queues work and returns `run_id`; bounded by `MCP_CREATE_RUNS_PER_HOUR`. |
| `cancel_analysis` | `cancel_run` | Requests cancellation at the next stage boundary. |
| `list_analyses`, `get_analysis` | run storage | History summaries or one full run. |
| `get_analysis_status` | `get_run_status` | Cheap polling result including `poll_after_ms`. |
| `get_decision` | `get_run_decision` | Available after the decision publishes. |
| `list_reports`, `get_report` | report readers | Progressive report discovery and one report body. |
| `get_chart_data` | artifact readers | Structured chart/market JSON and public artifact links. |
| `get_market_snapshot`, `get_earnings` | Alpha Vantage helpers | Same six-hour cache as HTTP. |
| `get_engine_info` | engine check | Safe service metadata and enabled tool names. |
| `list_ai_models` | provider catalogue | Configuration flags/model names only; never keys. |

### Security

`/mcp` is protected by a shared access key. Every HTTP request must send
`MCP_ACCESS_KEY` as `Authorization: Bearer <key>` or `X-MCP-Key: <key>`; anything
else is rejected with HTTP 401 before the MCP session manager runs. When
`MCP_ACCESS_KEY` is empty the endpoint is fully closed (fail closed). The key is
compared in constant time.

Example call:

```bash
curl -s https://engine.example.com/mcp \
  -H "Authorization: Bearer $MCP_ACCESS_KEY" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

The key is shared, not per-user, so treat it like a password and rotate it by
changing `MCP_ACCESS_KEY` and restarting. `FRONTEND_ORIGINS` is CORS, not MCP
authentication. Use network access controls as well for private deployments, set
`MCP_ENABLED=0` to disable MCP, or use `MCP_ALLOWED_TOOLS` to expose a smaller
tool set. No MCP tool returns secrets or changes provider configuration.
